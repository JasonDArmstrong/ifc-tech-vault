## **System and Control Panels**

- `sysdm.cpl` → System Properties (Computer name, performance, profiles, etc.)
- `appwiz.cpl` → Programs and Features (Uninstall/modify software)
- `ncpa.cpl` → Network Connections    
- `inetcpl.cpl` → Internet Properties    
- `desk.cpl` → Display settings    
- `powercfg.cpl` → Power Options    
- `timedate.cpl` → Date and Time    
- `control` → Opens classic Control Panel    
- `control printers` → Printers & Devices    
- `control userpasswords2` → Advanced User Accounts
## **Administrative Tools**

- `compmgmt.msc` → Computer Management    
- `eventvwr.msc` → Event Viewer    
- `secpol.msc` → Local Security Policy    
- `gpedit.msc` → Local Group Policy Editor    
- `services.msc` → Services console    
- `taskschd.msc` → Task Scheduler    
- `perfmon.msc` → Performance Monitor    
- `rsop.msc` → Resultant Set of Policy    
- `fsmgmt.msc` → Shared Folders Management

## **User and Computer Management**

- `lusrmgr.msc` → Local Users and Groups (not in Home editions)    
- `dsa.msc` → Active Directory Users and Computers (RSAT required)    
- `dssite.msc` → Active Directory Sites and Services    
- `domain.msc` → Active Directory Domains and Trusts    
- `adsiedit.msc` → ADSI Edit (advanced AD management)    
## **Networking & Firewall**

- `wf.msc` → Windows Defender Firewall with Advanced Security    
- `firewall.cpl` → Basic Firewall settings    
- `ncpa.cpl` → Network Connections (repeated for importance)    
- `cmd` → Command Prompt    
- `powershell` → PowerShell    
## **Diagnostics and Monitoring**

- `dxdiag` → DirectX Diagnostic Tool (system info)    
- `msinfo32` → System Information    
- `resmon` → Resource Monitor    
- `perfmon` → Performance Monitor    
- `taskmgr` → Task Manager    

## **Disk and Storage**

- `diskmgmt.msc` → Disk Management    
- `dfrgui` → Defragment and Optimize Drives    
- `cleanmgr` → Disk Cleanup    
- `iscsicpl` → iSCSI Initiator    

## **Other Handy Run Commands**

- `mstsc` → Remote Desktop Connection    
- `notepad` → Notepad    
- `regedit` → Registry Editor    
- `gpupdate /force` → Force Group Policy update    
- `shutdown /i` → Remote Shutdown GUI    
- `shutdown /r /t 0` → Immediate reboot    
- `explorer` → Opens File Explorer    
- `control folders` → File Explorer Options
