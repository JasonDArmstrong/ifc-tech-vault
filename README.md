# IFC Audio/Video Systems — Obsidian Vault

This repository contains the Obsidian knowledge base for the audio and video systems at Immanuel Fellowship Church. It is maintained by the A/V tech team and used as the primary reference for volunteers who run sound and live streaming on Sundays.

## What's in This Vault

**User Guide** — Documentation for the full A/V system, organized by component and workflow. Covers the signal chain from microphone to speakers, the Yamaha DM3 mixing console, Shure wireless systems, cameras, recording software (Audacity, OBS), video editing (DaVinci Resolve), and live streaming to SermonAudio, Facebook, and YouTube.

**Procedures** — Step-by-step runbooks for running a service, including equipment startup, monitoring during the service, shutdown, and post-service audio/video export and upload.

**Configuration** — Saved settings for the DM3 and wireless systems, organized by speaker and mic scenario.

**Workbench** — Weekly Sunday service reports, soundboard adjustment notes, volunteer rotation, and task tracking. This is the operational area used week-to-week.

**Projects** — Ongoing improvement work, gear wishlist, training materials, and video editing notes.

## Tools Used

- [Obsidian](https://obsidian.md) — note-taking and knowledge base application
- Plugins: Dataview, Tasks, Templater, Calendar, Excalidraw, Kanban

## Contributing

Changes to the User Guide should reflect the actual current state of the equipment. When settings change, update the relevant Configuration note and log the change in `Logs/Change Log.md`.
